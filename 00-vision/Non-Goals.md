# PushPal — Non-Goals

Defining what PushPal is **not** is as important as defining what it is.

---

## MVP Non-Goals (V1)

These are explicitly out of scope for the initial launch:

| Non-Goal | Why Not |
|---|---|
| Chat / messaging | There are plenty of messaging apps. PushPal is about scheduled notifications. |
| Read receipts | Delivery status (sent/delivered/viewed) is sufficient for MVP. |
| Recurring reminders | Adds significant complexity. V2 feature. |
| Groups / multi-person | MVP focuses on 1-to-1 (couples, families). |
| Snooze / actions on notifications | MVP notifications are simple and dismissible. |
| Location triggers | Requires native app and location permissions. |
| Calendar sync | Adds integration complexity. Not core value. |
| Email / SMS fallback | Web Push only for MVP. Fallbacks are V2. |
| Rich notifications (images, actions) | Simple text notifications only. |
| Timezone handling | UTC only for MVP. |
| Native apps | PWA first. Prove value, then build native. |
| Monetization | Focus on product-market fit first. |
| Internationalization (i18n) | English only for MVP. |
| Dark mode | System default only. |

---

## Forever Non-Goals

These will **never** be part of PushPal:

| Non-Goal | Why Not |
|---|---|
| Social features (likes, comments, feeds) | PushPal is a utility, not a social network. |
| Advertising | PushPal will never show ads. |
| Data selling | User data is never sold. Period. |
| Chat rooms | PushPal is not a messaging platform. |
| Task management | PushPal sends notifications, not task lists. |
| Calendar management | PushPal reminds, it doesn't schedule your life. |
| File sharing | Notifications are text-based. |
| Video / voice calls | Not a communication tool. |
