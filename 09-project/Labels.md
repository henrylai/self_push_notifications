# PushPal — GitHub Labels

## Type Labels

| Label | Color | Description |
|---|---|---|
| `type/feature` | #0075ca | New feature or enhancement |
| `type/bug` | #d73a4a | Something isn't working |
| `type/chore` | #fbca04 | Maintenance, dependencies, config |
| `type/docs` | #0075ca | Documentation only |

## Label Usage Rules

1. Every issue must have exactly one `type/*` label
2. Every issue must have exactly one `priority/*` label
3. Every issue should have one or more `area/*` labels
4. Every issue should have one `epic/*` label (if applicable)
5. `status/*` labels are added/removed as workflow progresses
